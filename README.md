# Hackathon UPN IA

Repositorio para los entregables de los 8 equipos participantes.

## Cómo entregar
1. Haz fork de este repositorio (o usa el acceso de escritura si se te otorgó).
2. Sube tus archivos **solo** dentro de la carpeta de tu equipo: `equipo-1` … `equipo-8`.
3. Abre un Pull Request hacia `main` con el título `Entrega equipo-N`.
4. Completa el `README.md` de tu carpeta (descripción, integrantes, instrucciones de ejecución, enlace a demo).

## Estructura
```
equipo-1/  equipo-2/  equipo-3/  equipo-4/
equipo-5/  equipo-6/  equipo-7/  equipo-8/
```
